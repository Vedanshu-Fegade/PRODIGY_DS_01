PRODIGY_DS_01 — Population Data Visualization

A Python-based data visualization project completed as part of the Prodigy InfoTech Data Science Internship.

This project analyzes population data from Our World in Data and creates visualizations to understand population distributions across countries.

## 🌐 Live Demo

[View Live Project](https://vedanshu-fegade.github.io/PRODIGY_DS_01/)

📌 Project Objectives
Analyze population data using Python.
Identify the 15 most populous countries.
Visualize population distribution using charts.
Interpret the distribution of country populations.
Generate and save visualization outputs.
📊 Visualizations
1. Top 15 Most Populous Countries

A horizontal bar chart showing the 15 most populous countries in the latest available year.

2. Population Distribution

A histogram showing the distribution of population sizes across countries.

🔍 Key Findings
Data Year: 2023
Countries Analyzed: 256
The population distribution is strongly right-skewed.
A small number of countries have significantly larger populations than most countries.
